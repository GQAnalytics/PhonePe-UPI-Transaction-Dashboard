# 📊 PhonePe UPI Transaction Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive Excel dashboard designed to analyze PhonePe UPI transaction performance. It provides valuable insights into transaction trends, payment applications, transaction status, banking performance, regional distribution, transaction types, and time-based transaction patterns.

## 🎯 Objectives

- Analyze total transactions and transaction amount.
- Monitor daily transaction trends.
- Analyze UPI application performance.
- Compare transaction status and success rates.
- Identify top-performing banks.
- Analyze state-wise transaction performance.
- Compare different transaction types.
- Track hourly and day-wise transaction patterns.
- Monitor cashback and suspected fraud transactions.

## 📊 Dashboard Features

- Total Transaction Analysis
- Total Transaction Amount
- Total Cashback
- Success Rate
- Suspected Fraud Analysis
- Daily Transaction Trend
- UPI App-wise Transaction Analysis
- Transaction Status Analysis
- State-wise Transaction Amount
- Bank-wise Transaction Amount
- Transaction Type Analysis
- Hour-wise Transaction Analysis
- Day & Hour Transaction Heatmap
- Interactive Filters for City, Gender, Merchant Name & Merchant Category

## 💡 Key Insights

- Total transactions reached **5,02,887**.
- Total transaction amount was approximately **₹44.25 Cr**.
- Overall transaction success rate was **91%**.
- The dashboard provides a comparison of transaction performance across UPI applications.
- Bank-wise analysis highlights the highest transaction-contributing banks.
- State-wise analysis helps identify regional transaction patterns.
- Hour-wise analysis helps identify peak transaction periods.
- Transaction status analysis provides visibility into successful, failed, pending, and refunded transactions.
